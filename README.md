# 🏋️ Mr olympiano — Web App (PWA)

Aplicativo Web Progressivo (PWA) desenvolvido para acompanhamento de treinos de adaptação e retorno às atividades físicas, otimizado para dispositivos móveis (especialmente telas AMOLED).

## ✨ Funcionalidades

- **Ciclo de Adaptação (4 Semanas):** Organização estruturada de treinos por dias (Peito, Costas, etc.) e semanas (S1 a S4).
- **Cronômetro de Descanso Integrado:** Presets rápidos (`60s`, `75s`, `90s`, `120s`), ajustes finos (`-15s` / `+15s`), alerta sonoro e vibração nativa ao finalizar.
- **Persistência Local:** Histórico de treinos concluídos, cargas (`kg`) e evolução salvos diretamente no navegador (`LocalStorage` / `IndexedDB`), funcionando 100% offline.
- **Instalação Nativa (PWA):** Pode ser instalado na tela inicial do Android/iOS como um aplicativo independente, sem barra de navegador.

## 🚀 Como instalar no celular

1. Acesse o link publicado pelo GitHub Pages no navegador (**Google Chrome** no Android ou **Safari** no iOS).
2. Toque no menu do navegador (três pontinhos no Chrome ou botão Compartilhar no Safari).
3. Selecione **Adicionar à tela inicial** ou **Instalar aplicativo**.

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3 (Tema Dark / AMOLED)
- JavaScript (Vanilla)
- Web App Manifest & Service Worker (Offline-first)
